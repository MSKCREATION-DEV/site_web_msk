# Visual regression — MSK

1. Ouvrir le frame Figma de référence (Desktop 1440).
2. Ouvrir la page locale (`npm run dev`) à largeur 1440.
3. Vérifier : layout, spacing, typo, couleurs, radius, images, bordures.
4. Noter les écarts ; corriger ou documenter PENDING.
5. Ne pas « améliorer » le design.
